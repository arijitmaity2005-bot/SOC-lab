## Objective
## 🎯 Objective

Build a practical SOC L1 home lab using Wazuh SIEM to monitor Windows and Linux endpoints, collect real-time security telemetry, detect suspicious activities, perform File Integrity Monitoring (FIM), create custom detection rules, and automate incident response through Wazuh Active Response.

| Windows telemetry     | Sysmon                        |

- Ability to generate and recognize attack signatures and patterns.

- Development of critical thinking and problem-solving skills in cybersecurity.
